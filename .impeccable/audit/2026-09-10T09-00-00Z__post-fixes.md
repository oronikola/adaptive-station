## Remaining Gaps (for future passes)

### Responsive Design — still at 2/4
The portal is fundamentally desktop-first. The CSS shell handles sidebar collapse. Tables have overflow-x scroll. Filter bars wrap. The remaining gap is that **column-level responsive hiding** (showing fewer columns on narrow viewports) isn't implemented — but this is an expected trade-off for a complex desktop admin tool. Going from 1/4 to 2/4 is the realistic ceiling without a full mobile rework.

### Accessibility — still at 3/4  
Remaining gap: `role="status"` missing on dynamic status badges (sync status that changes on the page). These only affect users who need screen-reader announcements for live updates. Low frequency for this user type (office staff in browser). The `prefers-reduced-motion` handling is complete. HeadlessUI covers modal ARIA.
